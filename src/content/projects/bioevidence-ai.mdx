## Overview
BioEvidence turns the biomedical QA research pipeline into a working application where retrieval, reranking, generation, and citation validation can be inspected independently. Its Examples mode also provides a detailed view of TREC questions, evidence, answers, and citations.

## System design
- Pyserini/Lucene retrieval with reranking and evidence selection
- Local LLM generation followed by citation validation
- Python backend integrating PubMed/NCBI, Europe PMC, and ClinicalTrials.gov APIs
- Supabase authentication and application data
- Next.js interface for live questions and detailed TREC BioGen examples

## What was built
- Inspectable, stage-separated query-to-citation pipeline
- User-facing Next.js application for live answers and saved TREC example inspection
- Authentication and application data through Supabase

## Result
The TREC research pipeline and its evaluation artifacts now connect to a practical application with inspectable evidence, API-backed biomedical sources, and a complete user-facing workflow.
