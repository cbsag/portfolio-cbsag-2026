## Overview
Answer course-enrollment questions with a system that can combine structured academic rules and semantic search.

## System design
- Modeled courses, lectures, topics, students, and grades from CSV and JSON as RDF/RDFS
- Served the knowledge base through Apache Fuseki
- Generated dynamic SPARQL queries for natural-language questions
- Added LangChain and FAISS for vector and hybrid retrieval comparisons

## Results
- Built 43,291 RDF triples across 5,258 course URIs
- Implemented graph, FAISS vector, and hybrid retrieval paths
- Produced a common QA interface for side-by-side evaluation
